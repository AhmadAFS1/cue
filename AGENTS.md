# Working on Cue

Read `PROGRESS.md` before resuming changes. Keep it current after meaningful edits, validation results, installation changes, and blockers, as requested by the user.

For local macOS installations, use `npm run install:mac`. It preserves the saved certificate identity and checks signing continuity. Do not replace the installed app with an ad hoc signature: that was the confirmed cause of stale microphone and screen-recording grants.

Do not put API keys, private signing keys, credentials, or unrelated screen content in progress notes or logs. Distinguish automated geometry tests and browser previews from physical global-shortcut validation.
